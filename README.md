# GymTracker

Android-приложение для тех, кто ходит в зал: записывайте подходы, следите за питанием и смотрите, как растут веса.

## Скачать

**[⬇ Скачать GymTracker 2.0 (APK)](https://github.com/Yauheni575/GymTracker/releases/download/v2.0/GymTracker-2.0.apk)**

Все версии — на странице [Releases](https://github.com/Yauheni575/GymTracker/releases).

## Установка

1. Скачайте `GymTracker-2.0.apk` на телефон.
2. Откройте файл. Если Android спросит — разрешите установку из этого источника.
3. Нужен Android 8.1 или новее.

## Что умеет

- **Анкета при первом запуске** — цель (масса, сила, похудение, выносливость), опыт, пол, вес, рост, возраст и частота тренировок. По ответам подбираются нормы питания, рабочие повторения и советы.
- **Тренировки** — каталог упражнений по группам мышц, избранное (☆), календарь всех тренировок. Подход записывается в пару нажатий: «+» повторяет прошлый подход, нажатие на строку — другой вес или повторения, долгое нажатие — удалить.
- **Какие мышцы работают** — карта мышц для каждого упражнения.
- **Питание** — поиск продуктов по названию или по штрихкоду, свои продукты (значения на 100 г с упаковки), дневная норма калорий, белка и воды.
- **Прогресс** — графики роста рабочих весов, объём по неделям за последние 8 недель, рекорды, вес тела.
- **Советы** — что делать на следующей тренировке, на основе ваших результатов, питания и анкеты.
- **Профиль** — ваши данные, цель, индекс массы тела, выход из аккаунта.
- Светлая и тёмная тема.

## Быстрый старт

1. Пройдите анкету или войдите в аккаунт.
2. На вкладке «Тренировки» нажмите «Упражнение» и выберите его из каталога.
3. Нажмите «Записать подход» — укажите вес и повторения.
4. Через пару тренировок на вкладке «Прогресс» появятся графики.

## Для разработчиков

Java, Android SDK 35, minSdk 27. Сборка: `gradle assembleRelease`.
